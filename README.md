# Python Module 01

## Overview
Welcome to **Python Module 01: Memory Management, Object-Oriented Basics, and Functional Programming Concepts**. This module introduces key Python programming concepts. Each exercise focuses on practical coding techniques, helping you understand Python's core features.

---

## Objectives
By the end of this module, you will:

1. Understand how Python manages memory and references.
2. Practice creating and interacting with Python classes and objects.
3. Work with file handling and basic string manipulation.
4. Simulate logging systems and explore functional programming concepts.

---

## Exercises

### Exercise 00: BraiiiiiiinnnzzzZ
**Goal:** Create a `Zombie` class where each zombie can announce itself and is cleaned up automatically when no longer needed.
- Learn how to use constructors and destructors (`__init__`, `__del__`).
- Understand Python's memory management.

### Exercise 01: Moar brainz!
**Goal:** Implement a function to create a horde of zombies.
- Work with lists and loops to manage multiple instances of a class.
- Test for proper resource management and behavior.

### Exercise 02: HI THIS IS BRAIN
**Goal:** Work with references and memory addresses in Python.
- Use the `id()` function to explore variable references.
- Practice working with pointers and references in Python's context.

### Exercise 03: Unnecessary Violence
**Goal:** Implement class interactions using a shared `Weapon` object.
- Practice composition in object-oriented programming.
- Explore getter and setter methods.

### Exercise 04: Sed is for losers
**Goal:** Write a program to replace all occurrences of a string in a file.
- Learn file handling in Python (`open`, `read`, `write`).
- Practice error handling and string manipulation.

### Exercise 05: Harl 2.0
**Goal:** Create a logging system with different log levels.
- Understand and use private methods in Python.
- Map string inputs to methods dynamically using dictionaries.

### Exercise 06: Harl filter
**Goal:** Extend the logging system to filter messages based on log levels.
- Simulate a switch-like construct in Python using dictionaries.
- Practice hierarchical data processing.

   - For example:
     ```bash

     ```

   - Validate each implementation with custom test cases.
